# Operating System Laboratory Repository

This repository contains my practical work, class activities, and assignments for the **Operating System** course.  
The purpose of this repository is to document my learning progress through hands-on exercises, simulations, and small projects related to operating system concepts.

## Course Overview

The Operating System course focuses on the fundamental concepts that allow a computer system to manage hardware and software resources efficiently.  

Through this course, I study both theoretical concepts and practical implementations, including process management, threads, CPU scheduling, synchronization, deadlock, memory management, and basic system-level programming ,  and also **LINUX CLI** specifically **Ubuntu**.

This repository mainly contains simulation programs, coding exercises, and class activities that help demonstrate how operating system concepts work in practice.

## Topics Covered

Some of the main topics included in this repository are:

- Process and process states
- Threads and multithreading
- CPU scheduling
- Process synchronization
- Semaphores and mutexes
- Deadlock and deadlock prevention
- Memory management
- File system basics
- Shell scripting and system programming exercises
